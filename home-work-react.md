# Домашнє завдання з React: Управління глобальним станом за допомогою React Context (useContext) 🌐🌓

## Завдання: Тематизація інтерактивного лічильника

Це завдання є прямим продовженням вашої попередньої роботи — **"Інтерактивний лічильник"**. Ваша мета — додати в додаток підтримку світлої та темної теми оформлення за допомогою **React Context** та хука **`useContext`**.

Всі компоненти додатку (лічильник, кнопки, історія лічильника) мають динамічно адаптувати свій зовнішній вигляд під активну тему без проп-дрилінгу.

---

### Вимоги до виконання:

#### 1. Створення файлу контексту теми (`ThemeContext`)
*   Створіть окрему папку `src/context/` та файл `ThemeContext.tsx` в ній.
*   Опишіть типи для теми (`"light" | "dark"`) та контексту.
*   Створіть контекст теми за допомогою `createContext()`.
*   Реалізуйте компонент-провайдер `ThemeProvider`, який:
    *   Зберігає поточний стан теми в `useState`.
    *   Містить функцію `toggleTheme()` для перемикання теми (зі світлої на темну і навпаки).
    *   Передає об'єкт `{ theme, toggleTheme }` у провайдер.
*   Напишіть та експортуйте кастомний хук `useTheme()`, який дозволяє зручно споживати тему та викидає помилку, якщо його викликано поза межами `ThemeProvider`.

#### 2. Підключення провайдера теми
*   Обгорніть ваш кореневий компонент додатку (`App`) компонентом `ThemeProvider` у файлі `src/main.tsx` (або `src/index.tsx`), щоб контекст був доступний усім частинам програми.

#### 3. Компонент перемикання теми (`ThemeToggler`)
*   Створіть окремий компонент кнопки `ThemeToggler`.
*   Використайте всередині нього хук `useTheme()` для отримання поточної теми та функції `toggleTheme()`.
*   Кнопка має відображати відповідну іконку або текст в залежності від теми (наприклад, `🌙` для темної, `☀️` для світлої) та міняти тему при натисканні.
*   Розмістіть цей перемикач угорі сторінки додатку.

#### 4. Адаптація стилів під тему (Світла / Темна)
*   Модифікуйте компоненти вашого лічильника:
    *   Фон сторінки (`body` або загальний контейнер додатку) має змінюватися на темний (`#1e272e`) або світлий (`#f0f2f5`).
    *   Сам блок відображення лічильника та кнопки керування (`+`, `-`, `Reset`) мають змінювати колір фону, рамок та тексту.
    *   Список історії лічильника (останні 5 значень) також має адаптувати свої стилі.
*   **Рекомендація:** Додавайте додаткові класи (наприклад, `.dark-theme`, `.dark-btn`, `.dark-history`) до елементів за допомогою звичайної шаблонної інтерполяції рядків або утиліти `clsx` (якщо вона підключена).

---

### Додаткові завдання (необов'язково, для підвищення оцінки):

1.  **Локальне збереження теми (localStorage):**
    Зробіть так, щоб обрана тема користувача зберігалася в `localStorage`. При перезавантаженні сторінки додаток має автоматично встановлювати раніше обрану тему.
2.  **Плавні переходи (CSS Transitions):**
    Додайте до ваших CSS-стилів властивість `transition: background-color 0.3s ease, color 0.3s ease;` для елементів, які змінюють колір, щоб перемикання теми відбувалося плавно та приємно для очей.

---

### Вказівки щодо подання:

*   Використовуйте свій попередній проект з інтерактивним лічильником.
*   Створіть нову гілку `feat/theme-context` або реалізуйте зміни безпосередньо в основній гілці.
*   Надішліть посилання на оновлений репозиторій або zip-архів з проектом (папку `node_modules` додавати не потрібно!).

*Завдання допоможе вам закріпити знання про передачу глобального стану в React, структурування провайдерів та роботу з хуком useContext.*
