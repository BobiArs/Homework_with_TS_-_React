# MovieRoulette: Інструкція з розробки додатку

**MovieRoulette** — це інтерактивний веб-додаток на базі React, Vite, Tailwind CSS v4 та TMDB API для вирішення одвічного питання кіноманів: «Що подивитися сьогодні ввечері?».

Користувач обирає фільтри відповідно до свого настрою, максимальної тривалості чи епохи виходу фільму. Після натискання кнопки запускається ефектна кругова рулетка з фізикою тертя та гальмування. Вибраний фільм відкривається в красивому glassmorphic-вікні з YouTube-трейлером, описом, акторами та офіційними стрімінговими сервісами (Watch Providers).

---

## 🏗 Архітектура проекту: Feature-Sliced Design (FSD)

Додаток розробляється з використанням сучасної модульної методології FSD, де проект розділений на логічні шари (layers):

1. **`app/`** — конфігурація додатку: роутер, глобальні провайдери (React Query), базові стилі.
2. **`pages/`** — сторінки додатку (основна `HomePage` із рулеткою та фільтрами).
3. **`features/`** — самодостатні інтерактивні фічі з бізнес-логікою:
   * `movie-filter` — панель налаштування фільтрів за настроєм.
   * `movie-details` — модальне вікно з трейлером та стрімінговими провайдерами.
4. **`entities/`** — бізнес-сутності додатку: типи даних фільму, хуки для запитів.
5. **`shared/`** — перевикористовувані утиліти та компоненти загального призначення:
   * `api` — налаштований клієнт Axios до TMDB.
   * `ui` — інтерактивний холст Canvas для рулетки (`RouletteWheel`).
